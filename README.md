# Projeto-algoritmos
🚀Projeto prático para a disciplina de Algoritmos e Lógica de Programação IFPB - Campus Esperança(2026).

# Detalhamento:
A atividade consiste no desenvolvimento de um sistema de informação com
menu interativo. Na implementação será obrigatório o uso de estruturas de
dados (lista, pilha, fila, tupla, conjunto ou dicionário) para manter as
informações em memória RAM. Os dados devem ser persistidos em arquivo
texto para que, numa próxima execução, as informações da última sessão
sejam mantidas.

# Tema do Projeto - Controle de Estacionamento Rotativo:

Registra as entradas e
saídas de veículos de um estacionamento. Deve manter placa, marca,
modelo e hora de entrada. O menu deverá dispor, pelo menos, das
seguintes opções: Entrada, Saída, Listar veículos (placa, marca, modelo,
hora entrada, ordenados pela placa), Buscar pela placa, total recebido no
dia. Na saída deve comparar a hora de entrada e saída dar o preço. O
estacionamento custa R$5 as 3 primeiras horas e mais R$2 por cada hora
adicional.

# Linguagem de Programação Utilizada:

Python
